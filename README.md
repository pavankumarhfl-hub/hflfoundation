# HFL Foundation — Hope For Life

Production-oriented static website for HFL Foundation.

## Structure
- `index.html` — mission-first homepage
- `about.html` — organisation story and wider HFL ecosystem
- `initiatives.html` — Foundation, Education, Community and Cyber initiatives
- `impact.html` — existing impact figures
- `founder.html` — founder profile and organisational journey
- `contact.html` — foundation contact route
- `assets/style.css` — cinematic graphite/gold design system
- `assets/site.js` — accessible mobile navigation, scroll reveal and progress motion

The site deliberately keeps social-impact content separate from the HFL Tech technology website.
